# **1. ESSÊNCIA**

*O site em uma frase. Não o que faz — o que faz sentir.*

| Um designer que pensa como founder e entrega como engenheiro — sente-se a conversar com alguém que faz acontecer. |
| :---- |

Teste: Se mostrares esta frase a alguém sem contexto, consegue imaginar a experiência? Sim — alguém competente, directo, sem fluff.

# **2. PALAVRAS-GUIA**

*O filtro de todas as decisões. Lê esta secção antes de aprovar qualquer elemento — visual, código ou copy.*

| Palavra | O que significa neste projecto |
| :---- | :---- |
| Editorial | O site lê-se como uma publicação — hierarquia tipográfica, composição intencional, nada genérico |
| Peso | Tipografia bold, animações com inércia, contraste que se sente — o oposto de leve e decorativo |
| Directo | Zero jargão, zero fluff — cada frase e cada secção tem uma razão clara para existir |
| Respirável | Espaço negativo generoso entre secções — o conteúdo existe com ar à volta, nunca apertado |
| Credível | O site demonstra competência sem precisar de a declarar — o processo, os produtos, a metodologia falam |

### **Teste de Decisão**

*Antes de aprovar qualquer elemento, pergunta:*

* Isto é editorial?
* Isto tem peso?
* O Rodrigo aprovaria isto numa conversa honesta?

### **3.3 Como Soa o Site**

*Não áudio — ritmo. Isto guia o copywriting E o timing das animações.*

| Aspecto | Escolha |
| :---- | :---- |
| Frases | Curtas e directas — máximo 2 linhas por parágrafo, frases de impacto isoladas |
| Pontuação | Mínima — ponto final, vírgula. Sem exclamações, sem reticências. Pontos de interrogação raros. |
| Tom do copy | 1ª pessoa — conversacional, como se estivesse a falar directamente com quem lê |
| Ritmo de animação | Peso com fluidez — entradas com inércia (ease out com duração generosa), não staccato nem legato puro |
| Densidade de informação | Esparsa no topo (hero, statement) → progressivamente mais densa (metodologia, projetos, experiência) |

# **4. VIBES DE REFERÊNCIA**

*Máximo 6 referências, cada uma com uma frase do que vamos pegar.*

### **4.1 Referências Visuais**

* **danielgamble.com.au** — Processo numerado, texto rotativo no hero, accordion de serviços, tom estratégico. A estrutura narrativa do site.
* **igorsokoltsov.com** — Minimalismo editorial extremo, hero de texto puro com peso tipográfico, muito espaço negativo. O nível de restraint.
* **rachelhow.com** — Posicionamento pessoal claro e acessível, organização limpa, fundo branco. A clareza de "quem sou + o que faço".

### **4.2 Referências de Sentimento**

* **Dieter Rams na oficina** — Precisão funcional, nada decorativo, cada peça tem razão de existir. A metodologia como craft.
* **Aesop store** — Espaço, materiais honestos, tipografia como identidade. A sensação de entrar num espaço curado sem ostentação.
* **Uma boa conversa num café em Lisboa** — Directo, sem agenda escondida, confiante sem ser arrogante. O tom de voz.

### **4.3 Referências de Formato ★**

*Se este site fosse uma publicação impressa, seria uma monografia de processo — tipo livro de case study de um estúdio de design independente.*

* **Monocle** — Editorial limpo, grids com intenção, hierarquia tipográfica clara com contraste de pesos. A estrutura compositiva.
* **Étapes** — Design gráfico europeu, tipografia com personalidade, hierarquia não convencional mas funcional. O atrevimento controlado.
* **Case study books de estúdios de design (Pentagram, Manual Creative)** — Processo visível, resultados contextualizados, tipografia como elemento dominante. O formato de apresentação de trabalho.

# **5. MOMENTOS-CHAVE**

*Os momentos que definem a experiência. Se estes não funcionarem, nada mais importa.*

| Momento | Emoção Desejada | Metáfora | Métrica de Sucesso |
| :---- | :---- | :---- | :---- |
| Hero landing | 'Este tipo sabe o que faz' | Aperto de mão firme — confiança imediata | TTI < 3s, texto legível em < 1s |
| Texto rotativo | 'Ah, ele faz tudo isto' | Cartão de visita que se revela — cada faceta aparece | Dwell time no hero > 3s |
| Scroll para metodologia | 'Tem processo, não é cowboy' | Abrir um manual bem organizado | Scroll depth > 50% |
| Case study page | 'Fez isto sozinho em 10 dias?' | Ver o before/after de uma renovação | Time on page > 30s |
| Unicorn Studio background | 'Este site é diferente dos outros portfolios' | Entrar num espaço com atmosfera — não é flat | Qualitativo — wow factor |

# **6. ANTI-VIBES**

*Tão importante quanto o que queremos. Decisões que parecem seguras mas matam a identidade.*

### **❌ Proibido**

* **Portfolio de front-end developer** — o site anterior tinha esta energia. Este não é sobre código — é sobre processo e produto.
* **Dark mode com gradientes neon** — a direcção anterior era dark + amber. Agora é light + editorial + neutro.
* **Linguagem de CV** — "7+ years of experience in B2B SaaS" é para o LinkedIn. O site fala como pessoa, não como candidato.
* **Overload de animações** — GSAP em tudo é o oposto do que queremos. Animações com peso nos momentos certos, silêncio no resto.
* **Inter, Roboto, ou qualquer fonte "AI default"** — derogação documentada. Proibido como body ou display.

### **⚠️ Cuidado**

* **Demasiada explicação da metodologia** — mostrar o processo, não dar uma aula. Se parecer um curso online, cortou demais.
* **Textos longos no about** — conversacional sim, mas editado. Cada frase ganha o seu lugar.
* **Unicorn Studio em excesso** — 1-2 cenas máximo. Se parecer tech demo, perde o editorial.

# **7. ATMOSFERA SENSORIAL**

*Descreve a experiência em sentidos que não o visual.*

### **Sonora**

* O som de páginas a virar numa revista de design — papel grosso, silêncio entre secções
* Typing numa máquina de escrever mecânica — peso, intenção, cada letra conta

### **Tátil**

* Papel mate premium — não brilhante, não áspero. Liso com textura subtil.
* Pedra quente — os neutros warm da paleta Sandstone transmitem solidez sem frieza

### **Cinestésica**

* Folhear um livro de fotografia grande — scroll lento, cada secção merece uma pausa.
* Subir escadas largas de betão — cada step tem peso, mas o ritmo é natural e confortável.
